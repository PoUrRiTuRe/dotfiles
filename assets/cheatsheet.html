NEBULA · SHORTCUTS

Search them all with SUPER + K · media keys do the same as SUPER + ALT

Windows

SUPER+←↑→↓
focus a window
SUPER+CTRL+←↑→↓
move the window (also to the other monitor)
SUPER+SHIFT+←↑→↓
resize the window
SUPER+Left click
drag the window (SUPER + left click)
SUPER+Right click
resize the window (SUPER + right click)
SUPER+W
close the window
SUPER+SHIFT+F
toggle fullscreen
SUPER+SHIFT+V
toggle floating
SUPER+SHIFT+C
center the floating window
SUPER+SHIFT+P
pin the floating window on every workspace
SUPER+J
switch split (side by side / stacked)
ALT+Tab
next window (like Windows' Alt + Tab)

Help

SUPER+K
search every shortcut (this menu)
SUPER+H
Serpantinum guide and settings

Session

SUPER+L
lock the screen
Power
lock the screen (power key)
SUPER+SHIFT+Esc
log out (back to the login screen)
Lid closed
lock when the lid closes (laptop)

Workspaces

SUPER+1 … 0
go to workspace 1 – 10
SUPER+SHIFT+1 … 0
send the window to workspace 1 – 10
SUPER+Tab
next open workspace
SUPER+SHIFT+Tab
previous open workspace
SUPER+X
show / hide the scratchpad
SUPER+SHIFT+X
send the window to the scratchpad

Apps

SUPER+B
browser (Brave)
SUPER+F
file manager (Dolphin)
SUPER+D
app launcher

SUPER+Print

SUPER+SHIFT+N

Terminal

CTRL+=
zoom in (kitty)
CTRL+-
zoom out (kitty)
CTRL+0
reset the zoom (kitty)
CTRL+ALT+C
copy the whole scrollback (kitty)
CTRL+ALT+X
copy the last command's output (kitty)
CTRL+L
clear the screen for real (scrollback saved first)

Media

play / pause
SUPER+ALT+→
next track
SUPER+ALT+←
previous track
SUPER+ALT+↑
volume up
SUPER+ALT+↓
volume down
SUPER+ALT+M
mute / unmute
Mic mute
mute / unmute the microphone
Brightness +
brightness up (laptop)
Brightness −

Shell

SHIFT+←→
select character by character
CTRL+SHIFT+←→
select word by word
CTRL+A
select the whole command (zsh)
CTRL+←→
jump word by word
CTRL+Backspace
delete the previous word (zsh)
CTRL+Delete
delete the next word (zsh)
Home
start of the line (zsh)
End
end of the line (zsh)
